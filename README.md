# ElectroMart Electronics Store Frontend

A responsive electronics-store frontend built with:

- HTML5
- CSS3
- Bootstrap 5.3
- Bootstrap Icons
- Vanilla JavaScript
- localStorage for cart and wishlist demo state

## Pages

Home, Shop, Categories, Product Details, Brands, Deals, New Arrivals, About, Contact, Login and Admin Dashboard.

## Dynamic frontend features

- Product listing/search
- Category filtering
- Product detail pages
- Cart quantity management
- Wishlist
- Product reviews UI
- Demo login
- Admin dashboard mockup
- Inventory/status display
- Responsive Bootstrap layout

## Run

Open `index.html` in a browser.

No backend/database is included. Product data is stored in `assets/js/data.js`, and cart/wishlist state uses browser localStorage.

For production, connect the forms, authentication, inventory, orders, reviews, and checkout to your backend/API.
